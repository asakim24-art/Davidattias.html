# Pick Them Pay 🛍️

חנות אונליין בסגנון AliExpress / Temu, בנויה עם Next.js ו-Stripe לתשלומים אמיתיים.

## מה יש באתר (שלב 1)

- **עמוד בית** — באנר ראשי, קטגוריות, "מבצעי בזק" עם טיימר, מוצרים מומלצים.
- **קטלוג מוצרים** — חיפוש, סינון לפי קטגוריה, מיון (מחיר/דירוג/הכי נמכר).
- **עמוד מוצר** — גלריה, מחיר/הנחה, תיאור, בחירת כמות, מוצרים דומים.
- **עגלת קניות** — נשמרת בדפדפן (localStorage), עדכון כמויות, הסרה.
- **תשלום אמיתי דרך Stripe Checkout** — מחירים מחושבים תמיד בשרת (לא נסמכים על הדפדפן), כולל דפי הצלחה/ביטול.

כל תוכן המוצרים כרגע הוא **דמו** (`src/data/products.js`) עם אייקונים/צבעים במקום תמונות אמיתיות — קל להחליף בהמשך.

## הרצה מקומית

```bash
npm install
npm run dev
```

האתר יעלה בכתובת http://localhost:3000

## חיבור תשלומים אמיתיים (Stripe)

1. פתחו חשבון ב-https://dashboard.stripe.com (יש מצב Test חינמי לבדיקות).
2. העתיקו את ה-**Secret key** מתוך https://dashboard.stripe.com/apikeys.
3. העתיקו את `.env.example` לקובץ `.env.local` ומלאו:
   ```
   STRIPE_SECRET_KEY=sk_test_...
   STRIPE_CURRENCY=ils
   ```
4. הפעילו מחדש את השרת (`npm run dev`).
5. לבדיקה: בקופה (Checkout) של Stripe בסביבת Test אפשר לשלם עם כרטיס הבדיקה `4242 4242 4242 4242`, כל תאריך תפוגה עתידי וכל CVC.

⚠️ **חשוב:** אם חשבון ה-Stripe שלכם לא תומך בסליקת ₪ (ILS) — למשל אם עדיין לא אושר לחברה ישראלית — שנו את `STRIPE_CURRENCY` ל-`usd` עד לבירור מול Stripe, או בדקו ספק סליקה ישראלי חלופי (כגון Tranzila / Cardcom / PayPlus). כשה-`STRIPE_SECRET_KEY` לא מוגדר, כפתור התשלום בעגלה יציג הודעת שגיאה ברורה במקום לקרוס.

כדי לעבור לתשלומים אמיתיים (לא רק בדיקה) — מחליפים ל-Live keys (`sk_live_...`) רק אחרי שהחשבון אושר לגמרי ע"י Stripe.

## החלפת הלוגו

יש כרגע לוגו טקסטואלי זמני ב-`public/logo.svg` (הקובץ ששלחתם היה הצעת מחיר לאחסון VPS ולא קובץ לוגו). שלחו לי את קובץ הלוגו האמיתי (PNG/SVG) ואשלב אותו באתר. אפשר גם להחליף ידנית: שימו קובץ `logo.png` או `logo.svg` בתיקיית `public/` ועדכנו את הנתיב ב-`src/components/Header.js`.

## החלפת/הוספת מוצרים

כל המוצרים מוגדרים בקובץ `src/data/products.js`. כל מוצר הוא אובייקט עם `id`, `category`, `name`, `price`, `originalPrice` (אופציונלי, ליצירת מבצע), `description`, ו-`emoji`/`color` (להחלפה בתמונה אמיתית מוסיפים שדה `image` ומעדכנים את `ProductTile`).

## מבנה הפרויקט

```
src/
  app/                # דפי Next.js (App Router)
    page.js           # עמוד בית
    products/         # קטלוג + עמוד מוצר בודד
    cart/             # עגלת קניות
    checkout/         # דפי הצלחה/ביטול תשלום
    api/checkout/     # יצירת Stripe Checkout Session
  components/         # רכיבי UI (כרטיס מוצר, הדר, פוטר וכו')
  context/CartContext.js  # ניהול עגלת הקניות בצד לקוח
  data/products.js    # קטלוג מוצרים וקטגוריות
  lib/stripe.js        # לקוח Stripe
```

## מה עוד כדאי להוסיף בהמשך

- מסד נתונים אמיתי למוצרים/הזמנות (כרגע הכל בקובץ סטטי, אין שמירת הזמנות).
- Webhook מ-Stripe (`checkout.session.completed`) לעדכון סטטוס הזמנה אוטומטי.
- מערכת התחברות/הרשמה למשתמשים והיסטוריית הזמנות.
- ניהול מלאי ופאנל ניהול למוכרים (כמו באליאקספרס האמיתי).
- תמונות מוצר אמיתיות במקום האייקונים הצבעוניים.

## פריסה (Deploy)

הכי פשוט לפרוס ל-[Vercel](https://vercel.com): מחברים את המאגר, מגדירים את משתני הסביבה (`STRIPE_SECRET_KEY`, `STRIPE_CURRENCY`) בהגדרות הפרויקט, ולוחצים Deploy.
